## Key Integration Dependencies

The following features share underlying logic and should be built together to maximise reuse:

### Financial Calculator Stack
Features **2.1 → 2.5 → 2.2 → 2.3 → 2.4** share a common cap table data model and should be built as a unified Financial Modelling Module with shared state:
- SAFE stack model feeds into cap table
- Cap table feeds into VC Method valuation
- VC Method feeds into IRR/MOIC
- All outputs feed into the Scenario Fundraising Planner

### Due Diligence Stack
Features **6.1 → 6.2 → 6.13 → 8.4** share a checklist completion framework:
- DD Readiness Check (quick scan) → surfaces priorities
- Full 39-item DD Checklist (detailed tracking)
- Document Completeness Scorer (AI layer cross-referenced with deal room)
- DD Readiness Report (export)

### Funding Intelligence Stack
Features **3.6 → 9.3 → 10.7** are tightly linked:
- 2026 Benchmarks Database (data source)
- Funding Milestone Navigator (consumer of benchmark data)
- AI Milestone Gap Analyser (AI interpretation layer)

## Implementation Notes

### Data Requirements
- **SAFE Calculator**: Requires no new database tables; purely computational frontend tool
- **Cap Table Builder**: Requires a new `capTables` and `capTableRounds` schema for persistence
- **DD Checklist**: Requires a new `dueDiligenceItems` table linked to `startups`; status tracking per item
- **Benchmarks Database**: Requires a new `fundingBenchmarks` table seeded with 2026 stage/sector data
- **Document Gap Finder**: Leverages existing `dealRoomDocuments` table; new AI service layer only

### UI Approach
- Financial calculators should be real-time (reactive state, no submit button) — results update as inputs change
- Checklist features should persist state to the database with auto-save
- Assessment tools (Founder DNA, Leadership Diagnostic) should use a step-by-step wizard UI
- All calculators should have a "copy results" and "download as PDF" action

### AI Integration Points
- SAFE Stack Summariser: Mistral Large with structured JSON extraction from uploaded SAFE PDFs
- Document Gap Finder: Cross-reference `dealRoomDocuments` filenames + content against DD checklist item keywords
- Milestone Gap Analyser: Mistral Large comparing startup metrics against seeded 2026 benchmark data
- Valuation Narrative Generator: Mistral Large with VC Method outputs as structured context
